2- À quoi sert la propriété CSS : display: flex Elle permet de créer un conteneur flexible pour aligner et distribuer l'espace entre ses éléments enfants facilement, de manière horizontale ou verticale.
3- Citez trois balises HTML utilisées dans les formulaires <input>, <textarea>, et <button> (ou <select>).
4- Que produit le code suivant :

Bienvenue

Il va afficher "Bienvenue" comme un grand titre en couleur rouge
5- Expliquez la différence entre id et class Un id est unique et ne peut être utilisé qu'une seule fois par page pour identifier un élément précis. Une class peut être réutilisée sur plusieurs éléments pour leur appliquer le même style.
6- Quelle propriété CSS permet de :
a - changer la couleur du texte
b- changer la couleur de fond		 a) color
b) background-color
7- À quoi sert l'attribut href dans une balise <a> Il indique la cible du lien hypertexte, c'est-à-dire l'adresse URL (ou le chemin du fichier) vers laquelle l'utilisateur sera redirigé au clic.
8- Quelle est la différence entre une balise block et une balise inline Une balise block commence toujours sur une nouvelle ligne et prend toute la largeur disponible. Une balise inline ne commence pas sur une nouvelle ligne et ne prend que la largeur nécessaire à son contenu.
9- Rôle des balises HTML : <head>, <body> <head> contient les métadonnées, le titre de la page et les liens vers les fichiers CSS (informations invisibles pour l'utilisateur). <body> contient tout le contenu visible de la page (textes, images, tableaux, etc.).
10- Définition de HTML et CSS HTML (HyperText Markup Language) est le langage de balisage utilisé pour structurer le contenu d'une page web. CSS (Cascading Style Sheets) est le langage utilisé pour mettre en forme et styliser cette structure (couleurs, polices, disposition).
